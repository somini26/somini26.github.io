이번에는 교차로 공개된 RSA 소수의 비트를 이용해 p와 q를 복원한 과정을 정리해 보려고 합니다.

## 지그재그 Write-up

### 1. 문제 분석

문제는 일반적인 RSA 암호문과 함께 두 소수 p, q의 일부 비트를 공개합니다.

```text
mask_p = 0
mask_q = 0
```

```python
for i in range(512):
    if i & 1:
        mask_p |= 1 << i
    else:
        mask_q |= 1 << i
```

```text
mask_p = p & mask_p  # p의 홀수 번째 비트
mask_q = q & mask_q  # q의 짝수 번째 비트
```

즉 다음 정보가 노출됩니다.

- p: 1, 3, 5, ... 번째 비트
- q: 0, 2, 4, ... 번째 비트

각 소수의 절반만 공개된 것처럼 보이지만, n = p × q를 이용하면 나머지 비트도 복구할 수 있습니다.

### 2. 취약점

p와 q를 이진수로 표현하자.

```text
[
p = \sum p_i 2^i,\qquad q = \sum q_i 2^i
]
```

곱셈 결과 n = pq의 k번째 비트를 계산할 때 사용되는 값은 다음과 같습니다.

```text
[
S_k = carry_k + \sum_{i=0}^{k} p_iq_{k-i}
]
```

따라서:

```text
[
n_k = S_k \bmod 2
]
```

```text
[
carry_{k+1} = \left\lfloor\frac{S_k}{2}\right\rfloor
]
```

p, q는 모두 홀수인 소수이므로:

```text
[
p_0=q_0=1
]
```

k번째 단계에서 새로 등장하는 항은 다음 두 개다.

```text
[
p_kq_0+p_0q_k=p_k+q_k
]
```

그런데 문제에서 k가 홀수면 p\_k가 공개되고, k가 짝수면 q\_k가 공개됩니다. 따라서 항상 둘 중 하나를 알고 있으며, n의 해당 비트와 이전 단계의 올림값을 이용해 나머지 하나를 결정할 수 있습니다.

예를 들어 k가 홀수라면:

```text
[
q_k =
\left(
n_k-carry_k-\sum_{i=1}^{k-1}p_iq_{k-i}-p_k
\right)\bmod 2
]
```

이 과정을 최하위 비트부터 반복하면 p, q를 전부 복원할 수 있습니다.

### 3. Exploit

문제에서 출력된 n, e, c, mask\_p, mask\_q를 각각 아래 변수에 넣습니다.

```text
# n, e, c, mask_p, mask_q는 문제에서 출력된 값
BITS = 512
```

```text
p_bits = [0] * BITS
q_bits = [0] * BITS
```

```python
# 공개된 비트 복원
for i in range(BITS):
    if i & 1:
        p_bits[i] = (mask_p >> i) & 1
    else:
        q_bits[i] = (mask_q >> i) & 1
```

```text
# p와 q는 홀수 소수
p_bits[0] = 1
q_bits[0] = 1
```

```text
carry = 0
```

```python
for k in range(1, BITS):
    middle = sum(
        p_bits[i] * q_bits[k - i]
        for i in range(1, k)
    )
```

```text
    target = (n >> k) & 1
    partial = carry + middle
```

```python
    if k & 1:
        # 홀수 위치에서는 p_k가 공개되어 있음
        q_bits[k] = (target - partial - p_bits[k]) & 1
    else:
        # 짝수 위치에서는 q_k가 공개되어 있음
        p_bits[k] = (target - partial - q_bits[k]) & 1
```

```text
    total = partial + p_bits[k] + q_bits[k]
```

```text
    assert (total & 1) == target
    carry = total >> 1
```

```python
p = sum(bit << i for i, bit in enumerate(p_bits))
q = sum(bit << i for i, bit in enumerate(q_bits))
```

```text
assert p * q == n
```

```text
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)
```

```text
m = pow(c, d, n)
flag = m.to_bytes((m.bit_length() + 7) // 8, "big")
```

```python
print(flag.decode())
```

```text

```
